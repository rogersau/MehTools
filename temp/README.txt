WARDOGS Kill Timeline Scanner

1. Extract the complete folder.
2. Double-click WARDOGS-Kill-Scanner.exe.
3. Add multiple recordings or drag them into the window.
4. Choose Scan + create highlights, select an output folder, and leave it running.
5. The app scans every recording and then creates one clean filename_highlights.mp4 per recording.
6. Export timeline... saves a CSV.
7. Export editor markers... saves SRT markers using 10 seconds before and 5 seconds after each detected event, plus a START OF RECORDING note at 00:00.

Highlight creation runs in the background, merges overlapping or nearly adjacent events, and preserves all source audio streams through the final merge.
Keep the whole extracted folder together. No Python or PowerShell installation is required.
